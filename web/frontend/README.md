# React frontend

React 19, TypeScript, Vite 8, Tailwind CSS 4. This is the interface for the local prototype in the [root README](../../README.md).

Run `npm ci`, then `npm run dev` with FastAPI running on port 8011. Use port 5173 to match the existing backend CORS configuration. `npm run build` checks TypeScript and creates a production frontend bundle; it does not deploy the application.
